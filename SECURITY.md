# Security Policy

## Supported Versions

Only the latest released version of `snek` receives security fixes.

| Version | Supported |
|---------|-----------|
| latest  | yes       |
| older   | no        |

## Reporting a Vulnerability

**Do not open a public issue or Discussion to report a security
vulnerability.**

Use GitHub's private vulnerability reporting feature instead:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Fill in the form with the details below.

### Required report details

- Vulnerability description and impact.
- Reproduction steps or proof of concept.
- Affected version(s).

### Response expectations

You can expect an initial response within a few days. Once a fix is ready,
a new release will be published and the advisory will be disclosed publicly.
